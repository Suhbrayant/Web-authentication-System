# InternConnect

InternConnect is a PHP and MySQL web application for managing internship opportunities and applications.

The system provides separate dashboards for students and administrators, allowing students to browse internships and submit applications while administrators manage internship postings and review applications.

# Features

- User registration and login
- Role-based access for students and administrators
- Student dashboard
- Admin dashboard
- Internship posting and management
- Internship application tracking
- CV upload support
- Student profile management
- Messaging between students and administrators
- Notifications
- Responsive CSS design

# Technologies

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Apache/XAMPP

This project uses PHP sessions and password hashing for authentication.
For production use, update the database credentials, validate all user input, and avoid exposing database passwords publicly.
